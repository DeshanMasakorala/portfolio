# Deshan Masakorala — Student Portfolio

## Run locally
1. Extract this ZIP file.
2. Open the `deshan_portfolio` folder in Visual Studio Code.
3. Open `index.html` in a browser, or use the VS Code Live Server extension.

## Included
- Responsive portfolio with the five required navigation sections.
- CV PDF supplied for this portfolio.
- About, skills, thesis project and AI agency project starter content.
- 11 IBM certification cards. Each card has placeholders for certificate, presentation and screen recording.
- Task timeline for 30.09.2026 and 07.10.2026.
- Contact links and a mailto-based contact form.

## Important: personalise before submitting
Search in `index.html` for `placeholder-link` and replace each placeholder with your real:
- LinkedIn profile URL
- GitHub profile URL
- AI project live demo and repository URLs
- Certificate, presentation and recording file paths
- Task presentation, job posting and cover letter paths

Put certification files in a folder named `certificates` and update the matching links in `index.html`. Put project files in a `projects` folder if you want to link to them.

The CV PDF is included as `Deshan_Masakorala_CV.pdf`. It is the CV you supplied, not a newly redesigned ATS CV.

## Intro video
The About section currently has a small animated introduction panel. Replace it with a real video when you have recorded your introduction.
